# AGENTS.md

## Git

- После любых изменений файлов (`edit`, `write`) всегда добавляй их в staging: `git add -A`.
- Не выполняй `git commit` и `git push` без явной просьбы.
- Не добавляй в staging файлы, которые должны быть в `.gitignore` (сборка, `node_modules`, `.vite`, секреты).
- В конце ответа перечисляй, какие файлы попали в staging.
